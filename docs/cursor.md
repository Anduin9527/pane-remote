# Cursor 模块

中文 | [English](en/cursor.md)

手机上查看和操作电脑上的 [Cursor](https://cursor.com) IDE：会话列表、对话消息、发消息 / 停止 / 新建 / 分叉 / 置顶 / 归档、待办和未读、命令输出、项目文件、改动差异，以及 Cursor 内置浏览器的实时画面。

```bash
pane-remote enable cursor
```

开启后手机顶栏会多一个 Cursor 图标。

## 原理

Cursor 是 Electron 应用。用 `--remote-debugging-port=9333` 启动它以后，电脑上的 `agent/cursor-agent.mjs` 通过 Chrome DevTools 协议连到 Cursor 自己的页面：

- **会话列表、实时状态**：往页面里注入一段只读的观察脚本，读侧边栏和当前会话（会话 id、标题、状态、正在生成的文字、可选按钮）
- **完整历史**：只读打开 Cursor 自己的本地数据库（`~/Library/Application Support/Cursor/User/globalStorage/state.vscdb`），按会话读消息；只做主键查询，不复制、不全表扫
- **操作**：在 Cursor 页面里聚焦对应会话的输入框写入文字、点按钮；输入框里已经有字（你在电脑上打了一半）时不会写入
- **会话操作**：分叉（整段，或者从某一轮回复分叉）、置顶 / 取消置顶、归档，都是点 Cursor 自己的按钮；分叉后手机自动切到新会话
- **改动**：用 Cursor 记录的「改之前的原文」对比磁盘上现在的文件，生成差异（只读）
- **内置浏览器**：Cursor 的 Browser 面板打开网页后是一个独立的网页视图，预览页切到「Cursor 浏览器」来源就能看和操作
- **用量**：会话列表顶上显示本计费周期的用量（Auto / API 两部分的百分比、按金额已用多少、还剩几天），点一下刷新。用的是 Cursor 设置里 Usage 页同一个接口，令牌从上面那个本地数据库读，只在电脑上的内存里用，不发给手机、不落盘

不传画面，只传数据，所以网络差也跟手；内存里有上限（会话数、每个会话的消息数和长度），不往硬盘写缓存。

## 启动和重启

- Cursor 没开：手机上点「启动 Cursor」（或直接新建会话 / 发消息）会带调试端口启动，并显示进度
- Cursor 用普通方式开着：手机上显示「重启并接入」，确认后正常退出再带端口重开，窗口会恢复；有没保存的内容 Cursor 会先问你；正在跑的 Agent 会被打断
- 想以后都带端口：从手机启动一次就行；之后如果从 Dock 打开（没带端口），手机会提示重启接入

## 注意

- **调试端口能完全控制 Cursor**（也就间接能控制电脑）。它只监听 127.0.0.1，但电脑上的其他程序都能连。只在只有你自己用的电脑上开
- 这依赖 Cursor 的页面结构和本地数据格式，不是官方接口。Cursor 升级后可能需要更新 `agent/cursor-agent.mjs`（适配器带版本号的观察脚本会自动换新）
- 你在电脑上同时操作 Cursor 时，手机上的发送可能偶尔失败（比如会话刚切换输入框还没出来），会提示重发，不会发错会话
- Cursor 设置成需要批准命令时，「在等你」的识别靠侧边栏状态和页面上的按钮文字（Run / Accept / Skip 之类），没认出来的话打开会话在对话页底部也能看到
